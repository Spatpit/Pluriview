# Pluriview v0.6.7

This release introduces Saved Viewpoints and improves workspace persistence, recovery, and everyday interaction.

## Saved Viewpoints

- Save named canvas positions and zoom levels inside each workspace.
- Move smoothly between viewpoints with interruptible pan and zoom transitions.
- Access viewpoints from the View menu or the empty-canvas context menu.
- Use configurable shortcuts for direct access and previous/next navigation.
- Update, rename, delete, and briefly undo deleted viewpoints.
- Clearly indicates when the active viewpoint has been modified.

## Workspace Reliability

- Workspace, catalog, autosave, and settings files now use crash-safe writes.
- The previous valid save is retained instead of risking truncation of the live file.
- Missing or damaged workspace catalogs are rebuilt from valid workspace files.
- Restore a previous valid save as a separate recovered workspace.
- Changed workspaces save once per minute; unchanged workspaces produce no disk writes.

## Interaction Improvements

- Browser and stream URL dialogs now include Paste buttons and right-click Paste actions.
- Tiles stop exactly where they are released instead of continuing with momentum or a spring effect.
- Saved Viewpoints submenus remain visible near the right edge without moving the main context menu.

## Downloads

- **Lite:** Includes Pluriview and ANGLE without `libmpv-2.dll`.
