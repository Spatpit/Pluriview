# Pluriview v0.6.8

This release introduces the gold Canvas P logo and strengthens workspace recovery, source reconnection, and everyday reliability.

## New Look

- New gold, champagne, and olive Canvas P icon on a chocolate background throughout the app, taskbar, and system tray.
- Matching honey-gold accents in the source picker and canvas.
- Windows Task Manager now identifies the application as **Pluriview**.

## Workspace and Source Recovery

- A recovery screen offers retry and recovery options when a workspace cannot be opened. Editing and saving stay paused until a workspace opens successfully.
- Autosave and exit saves cannot overwrite a workspace that failed to load.
- Backup rotation validates saved documents and preserves valid backups when the primary file is damaged.
- Catalog recovery recognizes backup-only workspaces and preserves files that cannot yet be recovered.
- Unsupported document versions are preserved instead of being overwritten.
- Closed window sources stay inactive and reconnect through the same privacy filters as the window picker.
- Missing or corrupt images remain recoverable tiles, with **Retry Image** and **Locate Image** actions.

## Everyday Improvements

- **Ctrl+Z** restores the latest deleted tile batch, even after the Undo notification disappears. The shortcut can be changed in Settings.
- Undo restores an entire tile deletion batch, including stacking order, geometry, settings, and playlist links. Switching workspaces clears the previous workspace's undo state.
- Repeated **Send to Back** actions maintain the correct stacking order.
- Stream Audio Monitor shows starting, active, retrying, and failure status. Stopping monitoring no longer blocks the interface while a worker exits.
- Settings places Streamlink first and groups Saved Viewpoints shortcuts separately from general shortcuts.
- Updated image-decoding, logging, and JSON dependencies, along with the release workflow tools.

## Updating

Close Pluriview before replacing its executable and included `lib` folder. Keep your existing `pluriview_data` folder to retain workspaces and settings. Back up that folder before updating.

## Downloads

- **Full:** `Pluriview-v0.6.8-windows-x64-full.zip` includes Pluriview, ANGLE, and `libmpv-2.dll` for video tiles, playlists, and video wallpaper.
- **Lite:** `Pluriview-v0.6.8-windows-x64-lite.zip` includes Pluriview and ANGLE without `libmpv-2.dll`.
- **Checksums:** `SHA256SUMS.txt` contains SHA-256 hashes for both archives.

Keep the included `lib` directory beside `pluriview.exe`. Streamlink remains an optional separate install for supported stream URLs.
