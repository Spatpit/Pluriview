# Pluriview v0.6.9

Focus a tile with **F**, including on keyboards without a number pad. This small
update also makes the README easier to follow, with clearer setup instructions
and explanations of browser tiles, shared logins, ad blocking, and audio sharing.

## Focus shortcut

- **F** is the new default for **Focus current tile**. Press **Esc** to return to the canvas.
- Existing saved shortcuts stay unchanged. To switch from **Numpad 2**, open **View → Settings → Keyboard shortcuts** and change **Focus current tile** to **F**.
- Browser interaction shortcuts remain **Ctrl+B** and **Numpad 1**.
- Canvas shortcuts stay inactive while you interact with a browser page, so typing or using the site's player shortcuts does not move or change your canvas. **Esc** and the configured browser interaction shortcuts remain available.

## Optional support

The About dialog now includes a **Support on Ko-fi** link to
[Spatpit's page](https://ko-fi.com/spatpit). It opens in your regular browser,
and support is always optional.

## Updating

Close Pluriview before replacing its executable and included `lib` folder.
Keep your existing `pluriview_data` folder to retain workspaces and settings.

## Downloads

- **Full:** `Pluriview-v0.6.9-windows-x64-full.zip` includes video tiles, folder playlists, and video wallpaper support.
- **Lite:** `Pluriview-v0.6.9-windows-x64-lite.zip` supports windows, browser tiles, Spout2, images, and GIFs without the video runtime.
- **Checksums:** `SHA256SUMS.txt` contains SHA-256 hashes for both archives.

Keep the included `lib` folder beside `pluriview.exe`. Streamlink remains an
optional separate installation for supported stream URLs opened in video tiles.
