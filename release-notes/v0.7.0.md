# Pluriview v0.7.0

A refreshed interface, easier cropping, and new controls for using your canvas
as a desktop overlay.

## A clearer interface

- Refined charcoal surfaces and warm gold accents across the top bar, window
  picker, and right-click menus, with clearer headings and more readable controls.
- Compact menus with right-aligned shortcut hints that follow your configured
  bindings. Long menus scroll to keep actions accessible in smaller windows.
- Easier window searches with a clear button, helpful empty states, and full-name
  tooltips for shortened source names.
- A new blue filmstrip icon for folder playlists.
- Updated browser and stream dialogs with convenient Paste controls, recent
  websites, and stream quality choices that still accept custom values.

## Crop directly on the tile

Choose **Crop → Edit Crop** and drag the highlighted edge or corner handles.
Click empty canvas, press **Esc**, or choose **Finish Cropping** when done.
This replaces the external source-window region selector; **Alt+drag** remains
available. Crop editing works with windows, browsers, Spout2, images, GIFs,
and videos, including tiles pinned to the viewport.

## Desktop overlay controls

- **Always on Top** keeps Pluriview above ordinary windows. Toggle it from the
  empty-canvas right-click menu or the tray; your preference survives restarts.
- **Click Through**, available in the tray, passes mouse input to apps underneath
  while previews and playback continue. Turn it off or choose **Show Pluriview**
  in the tray to regain interaction. Click-through starts disabled on launch.

## Performance and fixes

- Fixed **Add Window** closing immediately when opened near a window edge.
- Window captures can resize on the GPU before readback, reducing CPU resizing
  work while retaining a fallback for unsupported devices.
- Fewer redundant GIF and video redraws, including those driven by off-screen
  videos, while preserving playback and animation timing.
- Background browser creation no longer takes keyboard focus.
- Canvas shortcuts stay inactive while browser and stream source dialogs are open.
- Updated the Windows capture integration and fixed oversized menu layouts.

## Known issue

In local testing, a workspace with six browser tiles used more CPU after the
tiles returned from off-screen than with the previous capture backend. The
cause is still being investigated.

## Updating

Close Pluriview before replacing `pluriview.exe` and the included `lib` folder.
Keep your existing `pluriview_data` folder to preserve workspaces, settings,
and browser data. Existing keyboard shortcuts are preserved.

## Downloads

Starting with v0.7.0, we are releasing only the **Full** package, with all
features and the video runtime included. The Lite package is no longer offered.

- **Full:** `Pluriview-v0.7.0-windows-x64-full.zip` — includes the video runtime
  for videos, folder playlists, and video wallpapers.
- **Checksums:** `SHA256SUMS.txt`.

Keep the included `lib` folder next to `pluriview.exe`. Browser tiles require
Microsoft WebView2 Runtime. Streamlink is an optional separate installation
for supported stream URLs opened in video tiles.
